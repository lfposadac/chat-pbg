# Reto universal: Screen Sharing sin app

Queremos enviarle a un cliente un enlace que pueda abrir desde su teléfono sin instalar una aplicación. Después de otorgar permiso, queremos poder visualizar su pantalla mientras navega por otros sitios web o aplicaciones para poder guiarlo remotamente.

Investiga:
1. ¿Qué es técnicamente posible?
2. ¿Qué no es posible?
3. ¿Qué diferencias existen entre iPhone, Android y desktop?
4. Si exactamente lo solicitado no es posible, ¿qué solución construirías para acercarnos lo máximo posible?

No necesitas desarrollar esta solución. Queremos investigación, razonamiento y una recomendación técnica. Cita las fuentes técnicas principales que utilizaste.
